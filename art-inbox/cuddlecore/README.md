## Use
Copy this cuddlecore folder into your existing whiskedaway-react/art-inbox/ directory. No existing WhiskedAway checkout was available in this workspace, so the requested folder structure has been packaged here under outputs/whiskedaway-react/.

These are concept references for a coherent Blender room. They are not a panorama or four geometrically registered faces. See notes.md for the model's layout authority and image drift corrections.

Images: built-in image generation. prompts.json contains the complete prompt/revision record; source-brief.txt preserves the supplied direction. The fabric names say "candidate" because repeat seams did not pass the edge check. No image is labeled as production-ready seamless.
